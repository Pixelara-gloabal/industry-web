# Manufacture Web

A premium B2B manufacturing website built with Next.js, TypeScript and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production build

```bash
npm run build
npm run start
```

## Client content to complete before launch

- Company name, logo, address, email and phone number
- Approved factory and product photography
- Verified product specifications, documents and application details
- Approved industry, certification and quality information
- Quote-form email destination or CRM integration

## Technology

- Next.js 15 and React 19
- TypeScript
- Tailwind CSS 4
- shadcn/ui components
- Lucide icons
